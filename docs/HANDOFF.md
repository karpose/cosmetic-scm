## 需求方回答过的问题

- 交付偏好：先要规划方案，再按方案做原型，再按原型搭正式工程。
- 生产模式：代工 + 自产混合。
- 规模：成长期，SKU 50–300，用表格或单一软件管理。
- 渠道：国内电商平台、线下经销 / 门店、私域 / 直营。不做跨境。
- 代工供料：品牌供料和工厂代采两种都有，比例相当。
- 原型形式：在线可试用的网页原型。
- 技术栈：需求方问“哪种比较好”，按推荐采用 Java Spring Boot + Vue 3 + MySQL。理由：国内招聘和外包最容易，与金蝶、用友、电商 ERP 对接资料最多，Spring 在权限、事务、审计方面成熟，便于满足 GMP 附 1 电子记录要求。

## 规划方案的关键结论

- 核心思路：以“批次追溯”为主线，一套主数据贯穿全链。
- 建设方式：混合方案。财务、通用采购库存、电商订单用成熟 ERP / 电商 ERP；配方合规、委托生产协同、批次追溯用行业方案或自建（本仓库即自建部分）。
- 路线图（约 18 个月）：准备期 1–2 月（主数据、选型、KPI 基线）→ 一期 3–8 月打通主线 → 二期 9–13 月代工厂门户、QMS、经销商门户、PLM → 三期 14–18 月 S&OP 预测、自产 MES、一物一码、BI。
- 一期验收门槛：任一批号 2 小时内出具完整正反向追溯链，主线业务停用表格。

## 原型验证过的业务行为（正式工程已实现）

- 先到期先出：自产面霜发料时，临近效期的旧苯氧乙醇批次被优先使用。
- 客户效期门槛：京东自营入仓要求剩余效期 ≥ 67%，临期批次被自动排除。
- 追溯：从角鲨烷原料批次一路查到京东出库单；代工成品能看到受托厂代采原料的外部批号。

## 正式工程相对原型新增的内容

- 上市放行只授予质量安全负责人角色，后端强制；关键签批要求再次输入密码。
- 多步写操作在单个数据库事务内完成，库存行锁，防止并发导致负库存。
- 物料平衡超限必须填写说明；成品无备案编号不能放行；解冻需质量安全负责人签批。
- 库存流水表、账号与角色管理、Docker 部署。
