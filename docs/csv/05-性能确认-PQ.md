# 性能确认（PQ）

上线后用**真实主数据和真实业务**运行一段时间（建议 1–3 个月），确认系统满足日常使用。

| 编号 | 确认内容 | 方法 | 合格标准 | 结果 |
| --- | --- | --- | --- | --- |
| PQ-01 | 主线业务全部在系统完成 | 抽查当月采购、放行、生产、出库单据，与线下记录核对 | 主线不再依赖表格；单据数量一致 | |
| PQ-02 | 追溯演练 | 质量部随机指定 3 个批号（含 1 个委托生产成品、1 个原料），计时出具完整追溯报告 | 每次 ≤ 2 小时，链条完整 | |
| PQ-03 | 模拟召回 | 选一个已出库批号，在验证环境走完召回（发起、通知、登记回收、关闭） | 通知客户无遗漏，回收数量与退货单一致 | |
| PQ-04 | 账实相符 | 月末对自有仓做一次全盘，用“盘点调整”录入 | 差异有记录、有原因，差异率在公司标准以内 | |
| PQ-05 | 效期管理 | 看板“临期占比”“呆滞库存”与实物抽查一致 | 一致 | |
| PQ-06 | 审计复核 | 按 SOP-04 每月复核一次审计日志 | 无未授权操作，异常已处理 | |
| PQ-07 | 备份恢复演练 | 按 SOP-01 在验证环境恢复最近一次备份 | 恢复成功，抽查数据完整 | |
| PQ-09 | 批记录实际使用 | 选 1 张自产工单在现场全程用电子批记录，与纸质记录并行对照 | 能及时填写，内容一致，工序和限度符合实际工艺 | |
| PQ-10 | 提醒有效 | 连续一周核对每日提醒和总览待办 | 一致，到期事项被及时处理 | |
| PQ-08 | 响应速度 | 高峰时段常用页面打开时间 | 主要页面 ≤ 3 秒 | |
