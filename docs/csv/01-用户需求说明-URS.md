# 用户需求说明（URS）

| 项目 | 内容 |
| --- | --- |
| 系统名称 | 化妆品批次主线系统 |
| 文件编号 | CSV-URS-001 |
| 版本 | 1.0 |
| 适用范围 | 品牌方（注册人 / 备案人）的采购、物料放行、委托 / 自有生产、成品上市放行、销售出库、退货、投诉召回、批次追溯 |

优先级：**关键**（直接影响产品质量、消费者安全或法规符合性）／**重要**（影响数据完整性或业务连续性）／**一般**。

## 一、批次与追溯

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-01 | 原料、包材、成品按批号管理；每个批号唯一，由系统生成 | 关键 |
| URS-02 | 任一批号能正向（发往哪些客户）、反向（用了哪些物料批次、受托厂代采原料批号）追溯，2 小时内出具完整链条 | 关键 |
| URS-03 | 销售记录包含批号、客户名称、地址和联系方式，可用于召回 | 关键 |

## 二、物料与供应商

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-10 | 只能向合格名录内、资质在有效期内的供应商 / 受托厂下单；资质到期前提醒 | 关键 |
| URS-11 | 禁用原料不能采购、不能进入 BOM；限用原料按成品净含量校验浓度上限 | 关键 |
| URS-12 | 收货的物料批次处于“待检”，检验放行前不能用于生产 | 关键 |

## 三、生产与放行

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-20 | 发料按“先到期先出”从已放行批次分配 | 重要 |
| URS-21 | 实际产量超出计划 95%–102% 时必须填写物料平衡说明 | 关键 |
| URS-22 | 委托生产在受托厂出厂放行后才能入库；记录受托厂的出厂检验报告和放行人 | 关键 |
| URS-23 | 成品必须由质量安全负责人上市放行，其他任何角色（包括管理员）都不能代签 | 关键 |
| URS-24 | 上市放行必须登记留样，保存期限 = 有效期 + 6 个月 | 关键 |

## 四、销售、退货、投诉与召回

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-30 | 出库只分配已上市放行的批次，并满足客户的剩余效期接收标准 | 关键 |
| URS-31 | 冻结的批次不能出库；分配后被冻结的批次在出库时再次拦截 | 关键 |
| URS-32 | 退货先进入隔离区，不能被分配出库；由质量人员判定转可售或报废 | 关键 |
| URS-33 | 不良反应投诉按严重程度在规定时限内完成监测上报，未上报不能关闭 | 关键 |
| URS-34 | 召回由质量安全负责人发起和关闭；发起时冻结批次，逐个通知收货客户，全部通知到位才能关闭 | 关键 |

## 五、电子记录与安全

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-40 | 每个用户唯一账号，按岗位授予角色；外部门户账号只能访问本单位数据 | 关键 |
| URS-41 | 关键签批（放行、拒收、冻结、解冻、报废、召回）要求签批人再次输入本人密码 | 关键 |
| URS-42 | 所有业务写操作留痕：操作人、时间、内容、原因；审计记录只增不改，不能删除 | 关键 |
| URS-43 | 密码复杂度、连续失败锁定、定期更换 | 重要 |
| URS-44 | 数据每日备份，可恢复；备份异地保存 | 关键 |
| URS-45 | 库存只能通过业务单据变化，每次变化有流水，不允许出现负库存 | 关键 |

## 六、对外

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-50 | 受托厂通过门户回传进度和完工申报，申报口径与品牌方入库一致 | 重要 |
| URS-51 | 经销商按可售库存下单，审核后按先到期先出发货，能看到发货批号和召回通知 | 重要 |
| URS-52 | 电商订单幂等接收，出库失败可追溯原因并重试；接口凭密钥访问 | 重要 |
| URS-53 | 消费者扫码查询正品与批次效期；召回批次提示停止使用 | 一般 |

## 七、附件与现场作业

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-54 | 检验报告、资质等附件与批次、单据关联保存，不能删除；文件被改动或丢失时能发现 | 重要 |
| URS-55 | 受托厂只能查看和上传本厂委托单的附件 | 重要 |
| URS-56 | 打印带二维码的批次标签；发料、出库时扫码核对批次，扫错当场提示，结果留痕 | 重要 |
| URS-57 | 按标准成本估算库存、临期、呆滞、隔离区金额，并显示未填成本的物料数 | 一般 |

## 八、配方、质量体系与批记录

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| URS-60 | 生效配方的任何修改都要经质量安全负责人批准；保留所有版本和变更原因 | 关键 |
| URS-61 | 原料发生变化的配方，完成对应备案后才能生效；注册证过期的产品不能上市放行 | 关键 |
| URS-62 | 已发料的生产单保留发料时的配方版本 | 关键 |
| URS-63 | 偏差有记录、调查和结论；重大及以上的偏差未关闭时，关联批次不能放行 | 关键 |
| URS-64 | CAPA 指定负责人和期限，完成后由他人验证有效性 | 重要 |
| URS-65 | 供应商和受托厂定期审核；不合格的停止下单；到期提醒 | 重要 |
| URS-66 | 留样有台账，领用留痕，保存期满前不能销毁 | 关键 |
| URS-67 | 自产批生产记录：开工前和完工后清场、按顺序执行、关键工序他人复核、记录不能修改；不完整不能入库 | 关键 |
| URS-68 | 过程检验超限必须记录，并自动进入偏差流程 | 关键 |
| URS-69 | 主要记录可以导出，导出留痕；到期和超期事项主动提醒 | 一般 |
| URS-72 | 上线时能录入现有库存，且保留批号、效期和放行依据；已放行批次的录入须质量安全负责人批准 | 关键 |
| URS-73 | 设备有台账和校准记录；校准过期或停用的设备不能用于生产记录；校准不合格能评估受影响的工单 | 关键 |
| URS-74 | 账号停用、角色调整立即生效；管理员不能给自己授予角色 | 关键 |
| URS-75 | 重复提交或多人同时操作时，单据和库存不出错：同一操作只生效一次，不超卖 | 关键 |
| URS-76 | 3 万批次、30 万审计日志规模下，30 人同时使用时主要页面 95% 请求不超过 3 秒；临期提醒不遗漏老批次 | 重要 |
| URS-77 | 首版配方可以批量导入；上线前能查看还缺什么才能投入使用 | 一般 |
| URS-78 | 用 Excel 导出的 CSV 能直接导入（常见编码和分隔符），不能识别的文件要说清楚怎么办；日期含糊时拒绝，不猜 | 一般 |
| URS-79 | 界面文字对比度达到 WCAG 2.1 AA，深浅色都可读；主要操作可以只用键盘完成，控件能被读屏软件念出名称 | 一般 |
| URS-80 | 扫码作业、门户和常用弹窗能在手机上使用：内容不超出屏幕，确认按钮够得到，要填的数量不需要横向滚动 | 一般 |
| URS-81 | 修改主数据和账号时审计日志记录修改前后的值；登录成功、失败和手工处理电商单都能查到操作人 | 关键 |
| URS-82 | 录入超出精度或范围的数量和超长文字时明确拒绝并说明原因，不悄悄改值 | 关键 |
| URS-83 | 登录过期时不丢失正在填写的内容 | 一般 |
| URS-84 | 只知道供应商或受托厂批号时，也能查到对应的系统批次和用了它的成品；追溯结果能打印成报告 | 关键 |
| URS-85 | 物料批次被冻结或判定不合格后，用它生产的成品不能放行；召回进行中批次不能解冻 | 关键 |
| URS-86 | 召回显示还在外面的数量（扣除普通退货）；期初批次上线前的发货不在系统里时能发起召回并有提示 | 一般 |
| URS-87 | 门户账号只能看到和操作本单位的数据；同一来源不能无限尝试登录；不能从响应判断账号是否存在；不能用默认或占位密钥部署 | 关键 |
| URS-88 | 看板金额、呆滞、投诉、放行周期和补货可用量与实际数据一致；已过期批次不算可用，并有提醒 | 关键 |
| URS-89 | 供应商能在线确认采购单、回复交期（修改要写原因并留痕）、发送货通知、上传 COA 和资质文件；只能看到本单位的单子和本单位账号上传的文件 | 重要 |
| URS-90 | 送货通知的数量不超过未收且未通知的数量；仓库收货时带入批号和日期，库存和批次仍由收货生成 | 重要 |
| URS-91 | 能看到每家供应商的准时交货（按第一次承诺的交期算）和综合评分；评分只作参考，不影响下单，不给供应商看 | 一般 |
| URS-92 | 供应商账号填了邮箱时，每天收到本单位的待确认采购单、临近或超期的交期和资质到期提醒 | 一般 |
| URS-93 | 向合格供应商询价；报价互相看不到，开标前内部也看不到价格；定标留痕，定标人不是询价人，不足 3 家或没选最低价要写原因 | 重要 |
| URS-94 | 只结算检验放行的来料批次，同一批次不重复结算；发票和对账单一致才能审批，审批人不是制单人，付款不超付 | 重要 |
| URS-95 | 单价和金额只给采购、财务、管理员和对应的供应商看 | 重要 |
| URS-96 | 来料可以退回供应商：质量签批后扣库存并留痕，追溯能查到；结算前退的不计货款，结算后退的在下一张对账单冲减 | 重要 |
| URS-97 | 可以导入原料法规目录（来源必填）；配方、下单、询价按目录校验，目录更严就按目录；法规变化后能看到不合规的生效配方 | 关键 |
| URS-98 | 每个产品的安全评估、功效宣称依据、标签对应配方版本，经质量安全负责人签批；配方变了能看到要重新评估 | 重要 |
| URS-99 | 可以登记稳定性试验，按时间点取样检测，结果不能改，不合格自动生成偏差，结论经质量安全负责人签批；能看到每个成品的保质期有没有依据；试验报告能打印；方案修改留版本和原因；录错的结果经另一位质量安全负责人批准才能更正，原值保留 | 重要 |
| URS-100 | 物料和成品可以有质量标准（版本管理、质量安全负责人签批）；有标准的批次放行前要逐项录入检验结果，系统判定，合格才能放行；不合格生成偏差；标准可以规定哪些项目能采用供方检验报告、最多连续几批，采用时留报告编号和扫描件；取样有记录；检验结果能导出 | 关键 |
| URS-101 | 新品可以立项、记录小试和中试；上市前自动核对配方、备案、合规资料、包材设计稿、稳定性、质量标准和中试，全部满足后由质量安全负责人批准上市 | 一般 |
| URS-102 | 受控文件有版本管理，每版带文件并经质量安全负责人签批，按生效日期确定现行版本，按周期提醒复审；相关岗位确认已读，有记录；需要时由质量人员登记培训考核结果，可以导出培训考核记录；能看出检查要点要求的制度哪些已建立；纸质副本登记持有人、发放、收回和遗失，旧版或作废副本提醒回收 | 关键 |
| URS-103 | 变更经质量评估和质量安全负责人批准，行动项全部完成后才能关闭，全过程可追溯；配方和标签设计稿的修改能关联到变更 | 关键 |
| URS-104 | 印刷包材的标签设计稿按版本管理，质量安全负责人对照成分表逐项评审后批准；配方变了能看到要重新评审；每家印刷供应商的样张经质量签样后，它送来的包材才能放行；能查到按哪一版印刷的批次 | 重要 |
| URS-105 | 每年按《化妆品生产质量管理规范检查要点（委托生产版）》逐项自查，按判定原则得出结论，发现的问题转 CAPA，经质量安全负责人签批，能打印自查报告 | 关键 |
| URS-106 | 质量安全负责人有任职档案（专业、5 年以上经验、任命文件），同一时间只有一位现任；协助履行职责的授权写明职责、事项和期限，只能授权法规允许的职责，有监督记录；能看出哪些有签批权限的账号没有任职或授权依据 | 重要 |
| URS-107 | 产品销售记录包括产品名称、注册证或备案编号、使用期限、净含量、数量、销售日期、价格，以及购买者名称、地址和联系方式；记录按出库时的信息保存，能按日期导出，缺的内容能看出来 | 关键 |
| URS-108 | 和每家受托生产企业的委托生产合同有登记：期限、覆盖的成品、物料采购分工和约定的质量责任事项，有签字扫描件，经质量安全负责人签批；能看出哪些委托单下单时没有合同依据，合同快到期能提醒，可以设为没有合同不能下委托单 | 重要 |
| URS-109 | 对每家受托生产企业的生产活动有监督记录：驻厂、现场检查、调阅受托方的批记录和检验放行记录，写明监督的环节和发现的问题；重大问题有整改（CAPA），一般问题有纠正情况；记录经质量安全负责人审核；有在做的委托单却很久没有监督的受托厂能提醒 | 重要 |
| URS-110 | 品牌方自己的仓库各区域和留样室有温湿度范围和记录：可以手工录入或导入记录仪数据，记录只增不改、录错的作废留痕；超出范围的能看出来并生成偏差评估影响；要求每天记录的漏记了能提醒 | 重要 |
| URS-111 | 能定期做召回演练（模拟召回）：选一批已发货的成品，系统列出要联系的收货客户和在外数量、受托生产企业和有库存的仓库，逐一登记联系结果和时间，算出用时和在外数量的定位率；没达标有整改（CAPA）；演练经质量安全负责人审核；演练不能影响正式库存和批次状态；超过周期没有演练能提醒 | 重要 |
| URS-70 | 开错的生产单、采购单可以取消或关闭，原因留痕；已开工的不能取消；取消后物料退回、不再计入在制和在途 | 重要 |
| URS-71 | 导出的数据完整，不因页面只显示部分而缺失；审计日志可按日期范围查询和导出 | 关键 |
