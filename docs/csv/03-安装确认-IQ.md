# 安装确认（IQ）

在**正式环境**逐项检查并记录实际值。每项附截图或命令输出。

| 编号 | 检查项 | 要求 | 实际值 / 证据 | 结论 |
| --- | --- | --- | --- | --- |
| IQ-01 | 软件版本 | 记录部署的 Git 提交号（`git rev-parse HEAD`），与验证冻结版本一致 | | |
| IQ-02 | 运行环境 | Docker、Docker Compose 版本；服务器操作系统；时区为 Asia/Shanghai | | |
| IQ-03 | 数据库 | MySQL 8，字符集 utf8mb4；Flyway 迁移记录（`flyway_schema_history`）到最新版本且全部成功 | | |
| IQ-04 | 密钥与配置 | `.env` 中数据库密码、`SCM_JWT_SECRET`（≥ 32 字符随机串）、管理员初始密码均已修改；`SCM_DEMO_DATA=false`；`.env` 权限仅限运维 | | |
| IQ-05 | 账号安全配置 | `scm.security.force-password-change=true`、`max-failed-logins=5`、`lock-minutes=15`、`password-max-age-days=90`（或按公司制度） | | |
| IQ-06 | HTTPS | 用 `docker-compose.https.yml` 启动；证书有效期；访问 http 自动跳转 https；响应头含 HSTS | | |
| IQ-07 | 自动备份 | backup 服务运行中；`./backups` 下出现当日备份且 `gzip -t` 通过；已配置异地同步 | | |
| IQ-08 | 健康检查 | `GET /api/health` 返回 `UP`；`docker compose ps` 中 backend 为 healthy | | |
| IQ-09 | 对接与扫码 | 如启用电商对接，`SCM_INTEGRATION_API_KEY` 已设置且只告知 ERP 厂商；`SCM_VERIFY_URL_PREFIX` 为正式域名 | | |
| IQ-10 | 初始账号 | 管理员首次登录已强制改密；按岗位建好账号，质量安全负责人角色只授予指定人员 | | |
