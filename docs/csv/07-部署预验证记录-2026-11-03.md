## 演练中发现并已修正

1. **备份脚本依赖宿主机目录挂载**：在不共享宿主机目录的 Docker 环境（如未配置挂载的 Colima）里，挂载进去的脚本目录是空的，备份容器起不来。
   已改为把脚本打进备份服务自己的镜像（`deploy/backup/Dockerfile`）。
2. **数据库密码出现在命令行**：mysqldump / mysql 用 `-p密码` 会告警，且进程列表可见。已改为 `MYSQL_PWD` 环境变量。

## 注意事项

- HTTPS 叠加配置把证书和 nginx 配置以目录挂载方式放进前端容器（证书不应打进镜像）。在 macOS 的 Docker Desktop / Colima 上测试时，
  项目目录需要在虚拟机的共享目录里；Linux 服务器上没有这个问题。
- http → https 跳转按标准 443 端口生成地址；如果对外 HTTPS 用非标准端口，需要相应修改 `deploy/nginx/https.conf`。

**未验证**：没有用真实的标签打印机、扫码枪和手机摄像头实测；标签版式只核对了 PDF 分页（60×40 mm 每张一页，A4 第 22 张才换页）。这部分在 OQ-32 现场执行。

### 演练中发现并已修正

1. **超限上传卡死约 60 秒且没有提示**：后端在解析阶段拒绝时没读完请求体就返回，和 nginx 互相等待直到超时，响应体还是空的。这个问题绕过 nginx 测不出来。
   已把 Spring 解析上限调到高于 nginx（30 MB），20 MB 的业务上限由 `AttachmentService` 判断；nginx 的 413 也改为中文 JSON。
2. **摄像头扫码在生产环境被禁用**：安全响应头是 `camera=()`，开发服务器不走 nginx，所以之前没发现。已改为 `camera=(self)`。
3. **附件文件丢失时只报“系统内部错误”**：已改为明确提示文件可能丢失、从备份恢复。
