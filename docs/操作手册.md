# 岗位操作手册

给实际使用系统的人看，按岗位写。上线切换的完整规程见 [SOP-09](csv/06-运维规程-SOP.md)，权限明细见 [README](../README.md)。

**怎么写出来的**：在空库上，只用页面按岗位走了一遍，从建账号到召回关闭。这条走查进了 CI（`frontend/e2e-empty/go-live.spec.js`），流程变了测试会失败。走查是脚本做的，不是真人，看不懂的地方告诉管理员。

协议价、补单价、委外加工费、寄存仓和超耗台账、客户应收和信用额度、各类看板这几节是对照页面写的，还没有进空库走查。

## 所有人

- **第一次登录**：管理员给的是初始密码，登录后必须先改密码才能用。密码至少 8 位，大写字母、小写字母、数字、符号中至少三类，不能包含账号名。密码 90 天过期。
- **登录过期**：用了 12 小时左右会弹窗要求重新输入密码。正在填的内容不会丢，输完密码再点一次提交就行。
- **连续输错**：同一账号连续错 5 次锁定 15 分钟，管理员可以解锁。同一网络出口 1 分钟内失败 20 次，会暂时不能登录，等 1 分钟。
- **签批密码**：放行、报废、召回这类操作要再输一次自己的登录密码，代表本人负责，不要让别人代输。
- **待办**：登录后先看“总览”，要处理的事都在这里，点“去处理”直接跳过去。
- **手机**：左上角的按钮打开菜单。扫码、经销商下单、受托厂申报可以在手机上用，其它页面建议用电脑。

## 系统管理员：上线第一天

打开“上线检查”，它实时列出还缺什么，“必须处理”的不解决主线走不通。按这个顺序做：

1. **建账号**（账号与权限 → 新增账号）。至少要有质量安全负责人和质量检验，放行和检验只有他们能做。管理员不能给自己加角色。
2. **建仓库**（主数据 → 仓库 → 新增仓库）。至少一个“自有仓”和一个“退货隔离区”。
3. **导入物料**（主数据 → 物料 → 批量导入）。点“下载模板”，在 Excel 里填好，另存为 CSV 后上传。先看预检结果，全部通过才能点“确认导入”。重新导入已有的编码时，留空的格不会改动，要清空到主数据页面改；会改动哪些内容，预检下方逐条列出，确认前核对一遍，特别是禁用和合格名录。批号这类长数字要先把 Excel 的列设成文本格式，否则会变成科学计数。
4. **导入往来单位**（主数据 → 往来单位 → 批量导入）。类别要写全称：物料供应商、受托生产企业、自有工厂、客户渠道。客户的联系人和地址要填，召回时要用。受托生产企业和自有工厂的生产许可证上标注了“具备眼部护肤类 / 儿童护肤类化妆品生产条件”的，在最后两列“许可标注眼部护肤类”“许可标注儿童护肤类”填“是”；物料模板最后两列“眼部护肤类”“儿童护肤类”按成品的备案类别填。
5. **导入配方**（主数据 → BOM → 批量导入首版配方）。供料方式填“品牌供料”或“工厂代采”。
6. **现有库存**由质量安全负责人导入（见下文），不要用采购单或生产单虚构。
7. 回到“上线检查”点“重新检查”，直到没有“必须处理”。“备案记录”这一项会提示核对自动生成的记录，请质量部核对类型和日期。

## 采购

1. **下单**（采购入库 → 新建采购单）：选供应商，添加物料和数量。灰色的供应商不在合格名录或资质过期，不能下单。
2. **收货**（点该单的“收货”）：填本次数量、供应商批号（来料标签上的）、生产日期，选入库仓。有效期留空按保质期推算。**供应商批号一定要填对**，供应商通报问题时只给得出这个号。
3. 确认收货后系统生成内部批号，批次是“待检”，不能发料，等质量放行。

多收、少收都可以：可以分几次收，到不了货的可以“关闭”，单据状态会保留记录。

**供应商协议价**（采购入库 → 供应商协议价）：谈好的价格按供应商和物料登记含税协议价、税率、生效日期，失效日期选填，只能给原料、包材、半成品。下采购单和补货建议生成采购单时，单价留空就带入下单当天有效的协议价，同一天有几条的取生效日期最新的；手填的单价和协议价不一样时，行下方会提示偏离。询价定标时勾选“同步将中标价沉淀为供应商协议价”，中标价直接成为协议价。不再用的点“停用”。单价和协议价只有采购、财务、管理员能看。

## 质量检验

1. **物料放行**（质量放行 → 物料待检 → 检验放行）：可以上传 COA，填检验报告编号和说明，选“合格，放行”或“不合格，拒收”，输密码后点“签批”。
2. **冻结**（批次追溯 → 查到批次 → 冻结受影响批次）：发现问题先冻结，冻结的批次不能发料和出库。
3. **处置退货**（销售退货 → 处置）：转可售或报废，要签批。召回回收的货只能报废。

## 质量安全负责人

1. **成品上市放行**（质量放行 → 上市放行）：逐项确认放行检查，填出厂检验报告编号、留样数量和地点，选“准予上市放行”，输密码后点“签批”。
   这些情况系统不让放行：有未关闭的重大偏差、注册证过期、**用到的物料批次被冻结或判定不合格**。
2. **发起召回**：见下面“投诉与召回”。
3. **解冻**（质量放行 → 已冻结批次）：要写原因并签批。召回进行中不能解冻。
4. **期初库存导入**（库存作业 → 期初库存导入）：按盘点表填模板，已放行的要有检验报告编号，成品还要有留样信息。

## 生产计划（委托生产）

1. **下单**（生产与委托 → 新建生产 / 委托单）：选生产方、成品、计划数量。选了受托厂和成品后，对话框里会显示依据的委托生产合同；没有覆盖这个成品的有效合同时显示提醒（默认仍可保存，总览会提醒；管理员打开开关后不能保存），合同见下面“委托生产合同”。成品标了眼部护肤类或儿童护肤类、生产方的许可项目没有标注相应生产条件的，对话框直接提示，不能保存：许可证上确实有标注的，先到“主数据 → 往来单位”给这家工厂勾上。
2. **发料**（点“发料”）：先看系统按“先到期先出”分配的批次，确认后点“确认发料”。工厂代采的物料不用发，完工时登记批号。
3. **完工入库**（点“完工入库”）：填实际产量、生产日期、入库仓，登记工厂代采物料的批号和用量，勾选“受托厂已完成出厂放行”。产量超出计划 95%–102% 要写物料平衡说明。入库后是“待上市放行”。
4. **附件**：生产单明细里可以传资料。**委托生产单上的附件受托厂都能看到**，内部调查、成本这类文件传到批次上。
5. **取消**：没开工的可以取消，已发料的自动退料。开工后或受托厂已回传生产中的不能取消。
6. **补料和余料退库**（只限已发料、还没完工的单子）：不够用时在生产单明细里点“生产补料（超耗领料）”，或在列表行上点“补料”，选品牌供料物料、填数量和原因，系统按“先到期先出”从自有仓追加发料。用不完的点“生产余料退库”，选批次、填数量和原因，退回原来的自有仓，最多退这个批次发给这张单的净数量。每一笔都列在明细的“发料 / 补料 / 退库流水”里。

### 自有工厂

先由主数据或生产岗位在“配方与备案 → 工艺路线”维护工序。工序记录在生产单明细里：先做开工清场，再逐道记录工序，关键工序要别人复核，最后做完工清场，都做完才能完工入库。过程检验超限不会拦住生产，但会自动生成偏差。勾了“须记录设备”的工序要选校准有效的设备。

### 受托厂寄存仓和物料超耗

- **寄存仓**：在“主数据 → 仓库 → 新增仓库”建一个类型为“代工厂寄存仓”的仓库，关联单位选这家受托厂。之后给这家受托厂的委托单发料时，品牌供料从自有仓发出后记到寄存仓，补料、余料退库同步增减，完工入库时按净发料量从寄存仓核销。没有寄存仓的受托厂照旧，发料直接从自有仓扣。建寄存仓以前已经发料的单子，补料和完工还按原来的方式，不会补记到寄存仓。
- **委外寄售料账**（生产与委托 → 委外寄售料账）：按受托厂和批次列出还在厂里的品牌供料、批次状态和有效期，采购、财务、管理员还能看到货值。去受托厂盘点或对账时点“导出委外寄售料账”。
- **物料超耗与平衡**（生产与委托 → 物料超耗与平衡）：逐张单、逐个品牌供料物料，对比理论标耗和净发料量（首次发料 + 补料 − 余料退库）。理论标耗按这张单的配方版本算，完工的按实产，没完工的按计划数量。多发的是“超耗”，少发的是“节余”。自产单的物料都算在内。页面显示最近 300 张单的明细和全部超耗项，页签上的数字是全部超耗项；更早的节余、平衡明细点“导出超耗台账”查看。
- **工厂收率对比**：按生产方和成品看完工批数、在制、超期和平均收率。

### 委外加工费

采购、财务或管理员在委托单行上点“加工费”，填含税单位加工费和税率，改已有的加工费要写原因。成品上市放行以后才能结算，结算见下面“对账结算”。委托单进了对账单就不能再改加工费，要改先作废对账单。

## 销售

1. **出库**（销售出库 → 新建出库单）：选客户、发货仓、成品和数量，下方预览系统分配的批次，确认后点“确认出库”。过期和不满足客户效期要求的批次不会分配。
2. **退货**（销售退货 → 登记退货）：选客户，选退回批次和数量（不能超过可退量），写原因。货先进隔离区，等质量处置。
3. **经销商订单**：经销商订单 → 审核，通过即按先到期先出出库。
4. **电商订单**：电商对接里能看到失败的单和原因，补货后点重试，或者取消。
5. **产品销售记录**（销售出库 → 产品销售记录）：选日期范围（默认最近 30 天，最多一年），看每张出库单每个批号的备案编号、限期使用日期、净含量、数量、价格和购买者信息，点“导出销售记录”存档或备查。“核对”一栏写着缺什么：购买者地址、联系方式和成品净含量到“主数据”补（成品可以填“标签净含量”，如 30mL），价格到“缺单价”补（见第 8 条）。出库时信息不全也能出库，系统会提示，出库单列表标“不全”。
6. **客户协议价**（销售出库 → 客户协议价 → 新增客户协议价）：按客户和成品填含税供货价、税率（留空取客户默认）和有效期，只给成品。出库和审核经销商订单时，单价留空就带入当天有效的协议价。只有销售、财务、管理员能看和维护。
7. **信用额度**：出库时提示“信用额度不足”的，见下面“客户应收和信用额度”。
8. **补单价**（销售出库 → 缺单价，销售、财务、管理员）：出库时没填单价、客户也没有协议价的行列在这里，页签上的数字是行数，总览也有“出库行没有单价”的待办。这些行补上单价前不进应收单、不占信用额度。可以按客户筛选，逐行填含税单价，税率留空沿用客户默认；有建议价的（出库那天有效的协议价、这个客户这个成品上一次的单价、现在的协议价）可以点“空着的按建议价填入”，核对后点“保存 N 行单价”。赠品、样品不收款的填 0，要写原因。补完的价马上计入客户额度，补完超出额度也照样保存，提示超额，之后的出库会被拦下。
9. **改单价**：出库单列表里有单价、还没进应收单的行后面有“改单价”，改价要写原因，审计里记下改前改后的价格。进了应收单的行不能改，要改先请财务作废那张应收单。

## 投诉与召回

**登记投诉**（销售、质量，投诉与召回 → 登记投诉）：选产品和批号，选类别和严重程度。不良反应有上报期限：严重的 7 日内，其它 30 日内，超期会在总览提醒。

**召回**（质量安全负责人）：

1. 在投诉行点“召回”，或点“发起召回”后填批号。弹窗会列出要通知的客户，写原因并签批。批次立即冻结。
2. **逐个通知**：详情里点“标记已通知”（质量或销售都可以）。
3. **登记回收**（销售或仓库）：详情里点“登记回收”，会打开已关联召回的退货单。
4. **关闭**：所有客户都通知后，写召回总结并签批。

如果只知道供应商或受托厂的批号，在“批次追溯”直接输入，系统会列出对应的批次。可以打印追溯报告存档。

期初导入的批次，上线前发给哪些客户不在系统里，要到旧系统或台账核对，线下通知后写进召回总结。

**召回演练**（质量人员，投诉与召回 → 召回演练）：模拟一次召回，看能多快把在外的产品找全。只是演练，不冻结批次、不通知客户、不改库存，可以用正式数据做。

1. **发起**：点“发起演练”，填一个已发货的成品批号，点“列出要联系的对象”，看到收货客户（带在外数量）、受托生产企业和有库存的仓库。写模拟的召回情景，填目标用时（质量部定，默认填 24 小时），点“发起演练”，开始计时。
2. **逐一联系**：在详情里每一行点“登记”。客户由销售或质量联系，可以填客户反馈还在手上的数量；受托厂确认能停止生产；仓库盘点后填实盘数量。联系不上的选“联系不上”并写试过的方式。联系时间留空按现在，事后补登可以填实际时间。
3. **提交**：都登记完，系统算出用时（到最后一家联系完）和在外数量定位率。有联系不上、实盘对不上或超时的算没达标，要先点“转 CAPA”填整改措施。写演练总结，点“提交审核”。
4. **审核**：质量安全负责人（不能是发起人或提交人）在列表上点“审核”，输入密码点“审核通过”；记录不全的点“退回”。
5. **到期提醒**：超过 12 个月没有审核过的演练，总览会提醒。

## 仓库

- **收货**：同采购的第 2 步。
- **调拨、盘点**：库存作业 → 仓间调拨 / 盘点调整，要写原因。
- **报废**：由质量人员在库存作业里发起并签批。
- **扫码**：扫码作业，发料和出库时逐个扫，不是本单的批次当场拦下。
- 过期物料会出现在总览待办，请交给质量处理。
- **温湿度**：每天在“贮存环境”录入各区域的温湿度，或导入记录仪数据（见下面“贮存环境”）。昨天漏记、还在超限的区域会出现在总览待办。

## 受托厂门户

登录后只能看到委托给本厂的单子。回传进度；完工后点“申报完工与出厂放行”，填成品批号、出厂检验报告编号、放行人和代采原料批号；可以传出厂报告。品牌方入库时会用这些内容。

**物料验收标准**（门户 → 物料验收标准）：品牌方提供给本厂的原料、包材（品牌供料）按在做的委托单列出，每个物料显示品牌方的验收标准（检测项目、方法、限度、判定标准、取样要求）和原料成分（INCI 名称、CAS 号）。按标准做来料验收，收到后点“确认收到第 n 版”；品牌方修订标准后会显示“确认的是旧版”，要重新确认。显示“品牌方还没有提供标准”的，请联系品牌方质量部。

**委外对账**（门户 → 委外对账）：品牌方生成加工费对账单后，在这里核对委托单号、产出批号、数量和加工费。没问题点“确认对账”，不对点“提出异议”写原因，品牌方采购会核对后重新生成。确认后点“登记加工费发票”，填发票号和开票日期。

## 供应商门户

登录后只能看到下给本单位的采购单，也只能看到本单位账号上传的文件。

1. **确认订单**：回复交期，也就是预计到达品牌方仓库的日期。之后可以修改，但要写原因，每次都有记录。**准时交货按第一次回复的交期计算**，所以第一次请填确实做得到的日期。
2. **填写送货通知**：发货时填数量、批号、生产日期。同一物料有多个批号时，分开发通知。发错了可以取消，收货后不能取消。
3. **上传附件**：每张单上传 COA 或检验报告。“本单位资料”里能看到资质到期日，有新证时上传，品牌方核对后更新。
4. 展开采购单上的**收货回执**，按批次查看收货日期、实收数量、供应商批号和当前质检状态。按送货通知收货时，通知下会列出数量或批号的差异。
5. 如需核对差异，在对应的送货通知下点**提交收货异议**，填写具体物料、数量或批号。采购答复后，在同一张通知下查看说明。

## 合规资料（合规 → 合规资料）

**产品档案**：每个成品要有已签批的安全评估和标签，功效宣称依据按实际情况。

1. **登记**：主数据或质量人员点“登记”，选资料类型，填标题和评估人，保存后上传报告文件。
2. **签批**：质量安全负责人签批，不能是登记人。系统只管有没有、谁签批、对应哪个配方版本，**不判断报告内容对不对**。
3. **配方变了**：旧版本的资料显示“要重新评估”，总览会提醒。配方变更时可以先为新版本做评估，再批配方。

“全成分表”按配方含量排序，**只是草稿**：复配原料没有拆开，配方外的成分（如水）不在里面，不能直接用于标签。

**法规目录**：**系统不内置法规内容。** 由质量人员按官方发布的版本填模板导入，来源必填。INCI 已存在的按整行覆盖，上限留空就是无上限；确认导入前，预检会列出类别、上限和状态的变化，请逐条核对。导入后配方保存和提交、采购下单、发起询价都会按它判断，比物料上标的更严就按目录。按 INCI 名称、别名和 CAS 号对照，所以原料至少要填 INCI 或 CAS 号（主数据里填，CAS 号保存时会检查校验位）。同一物质的其它写法（如旧名称）填在模板的“别名”列，分号分隔，别名不能和别的条目重复。“物料和目录不一致”和“生效配方不符合目录”都列在这一页，已生效的配方不会自动停用，要人工处理。上线前要停用示例条目。

合规资料默认不拦上市放行，资料补齐后请管理员打开开关（见 `docs/PLM-默认规则.md`）。

## 受控文件（合规 → 受控文件）

1. **新建**：主数据或质量人员点“新建文件”，填编号、名称、类别、复审周期。保存后在版本上传文件。
2. **签批**：另一位质量安全负责人打开文件，输入密码签批。**没有文件不能签批。** 可以指定以后的生效日期，到期前旧版照常使用。
3. **修订**：点“出新版”，写修订内容，上传新文件，再签批。
4. **已读确认**：质量人员在文件里设“需要确认的岗位”。这些岗位的人登录后，在“受控文件”顶部能看到“待我确认”，打开文件点“我已阅读并理解”。生效后 14 天还没确认完的，总览会提醒。
   要考核的文件，质量人员在“需要确认的岗位”里勾选“确认后还要考核”。大家确认已读后，质量人员线下考完，在已读确认区点“登记考核”，选日期和方式，逐人选通过或未通过（没通过要写原因），可以填分数。没通过的以后再登记一次补考。生效后 30 天还有人没考核通过的，总览会提醒。受控文件页右上角“导出培训考核记录”导出全部考核记录。
5. **复审**：到期前 30 天提醒。内容不用改的，质量安全负责人点“复审确认”；要改的就出新版。
6. **对应的制度**：新建文件时在“对应的制度”里选这份文件属于哪些制度（检查要点要求建立的），已有的文件在详情里点“修改”。“制度覆盖”标签页汇总每项制度有没有生效的文件，缺的要补；GMP 自查时相关项目也会提示。
7. **纸质副本**：QA 或 QSO 打开文件详情，点“发放纸质副本”，填写持有人或地点和份数（每次最多 20 份）。仅可发现行版本。收回时点副本旁的“收回”，遗失时点“遗失”并填写原因。新版生效或文件作废后，旧版副本应在 7 天内收回，总览会提醒。

## GMP 自查（合规 → GMP 自查）

按《化妆品生产质量管理规范检查要点（委托生产版）》24 项自查，每年至少一次。

1. **发起**：质量人员点“发起自查”，选自查期间（默认最近 12 个月），可以写自查范围。同一时间只能有一份在进行。
2. **逐项检查**：打开自查，每一项下面有检查要点；系统能核对的项目显示“系统核对”结果，红色的是发现了问题，要重点看。逐项选“符合 / 存在瑕疵 / 不符合 / 不适用”，填发现的问题和查看了哪些记录，点“保存第 N 项”。存在瑕疵只有关键和重点项目能选，不适用只有一般项目能选。上方实时显示按当前结果算出的结论。
3. **转 CAPA**：存在瑕疵或不符合的项目点“转 CAPA”，写整改措施、负责人和期限。CAPA 在“质量体系”里跟进。
4. **提交签批**：24 项都检查完、问题都转了 CAPA 后，点“提交签批”，写自查总结。另一位质量安全负责人打开自查，点“签批”输入密码；有问题可以退回。
5. **打印报告**：自查详情里点“打印报告”，A4 纵向，存档或报送时用。

## 质量安全负责人（合规 → 质量安全负责人）

质量安全负责人的任职档案和协助履职授权（检查要点第 4、5 项）。

1. **登记任职**：管理员先在“账号与权限”给这个人的账号加上“质量安全负责人”角色，再到本页点“登记任职”，选账号，填姓名、所学专业类别、学历、化妆品生产或质量管理经验年数（不少于 5 年）、任职日期和工作经历。
2. **上传材料并生效**：登记后弹出任职档案，上传任命文件和资质证明（学历、专业、工作经历证明），输入管理员密码点“签批生效”。新任生效后，原来的现任自动离任，原现任签的授权全部撤销，新任要重新授权。
3. **授权协助履职**：现任质量安全负责人点“授权协助履职”，选被授权人，勾选协助履行的职责（资料审核、物料和产品放行、不良反应监测），写明具体事项，选期限（最长 12 个月），输入自己的密码。被授权人要签批放行的，还要请管理员给他的账号加上“质量安全负责人”角色。
4. **监督和撤销**：授权期间现任至少每 6 个月点“监督”记录一次抽查情况；不再需要时点“撤销”并写原因。快到期的授权总览会提醒。
5. **账号核对**：“账号核对”列出所有有质量安全负责人角色的账号，不是现任、也没有生效授权的标为“没有依据”，总览也会提醒；要么补授权，要么去掉角色。
6. **离任**：现任离职或调岗，管理员在“任职档案”里点“离任”并写原因；在新任生效前，系统里没有现任，不能签授权。

## 委托生产合同（合规 → 委托合同）

和每家受托生产企业签的委托生产合同（含质量协议），检查要点第 8 项。

1. **登记**：采购、生产或质量人员点“登记合同”，选受托生产企业，填合同名称、合同编号、签订日期和期限，选合同覆盖的成品，再选原料、包材分别由谁采购（委托方提供、受托方采购、按 BOM 逐项约定），点“保存草稿”。系统按成品现行 BOM 的供料方式核对采购分工，不一致的会列出来（比如合同写原料由委托方提供，BOM 里却有工厂代采的），要么改 BOM，要么按实际约定改合同。
2. **上传和提交**：保存后弹出合同详情，上传双方签字盖章的扫描件，点“提交签批”。
3. **签批**：另一位质量安全负责人（不能是登记人或提交人）点“签批”，对照扫描件逐项勾选合同里写明的约定事项（质量安全责任、物料采购、检验、放行、监督、记录调阅、召回等），输入密码点“签批生效”。合同没写明的事项点“退回”并写原因，补签补充协议后再提交。合同里有眼部护肤类、儿童护肤类成品而受托厂许可项目没有标注相应生产条件的，详情里标红，不能签批。
4. **到期和续签**：执行中的合同到期前 30 天总览会提醒；登记并签批续签合同（覆盖同样的成品、到期更晚）后不再提醒。合同到期不用操作。
5. **终止**：更换受托厂或提前解除合作时，管理员或质量安全负责人在合同详情里点“终止合同”并写原因。终止前已下的委托单仍按这份合同执行，之后下的单没有合同依据。
6. **委托单核对**：“委托单核对”标签页列出还没完成的和最近 90 天的委托单，下单时没有合同依据的标红，总览也会提醒。

## 受托生产监督（合规 → 受托生产监督）

对受托生产企业生产活动的监督，检查要点第 9 项（生产过程、检验、放行）和第 18 项（调阅受托方保存的记录）。

1. **登记**：质量或生产人员点“登记监督”（也可以在“受托厂”“委托单”标签页的行上点“登记监督”，会带出受托厂和委托单），选受托生产企业，针对某张委托单的选上委托单，选监督方式（驻厂监督、现场检查、调阅记录、远程视频）和日期，勾监督的环节，写参加人员和监督情况，点“保存记录”。
2. **登记问题**：保存后弹出记录详情。发现问题的，选“一般问题”或“重大问题”，写明问题，一般问题当场纠正了的顺手写上纠正情况，点“登记问题”。一般问题后来才纠正的点“写纠正情况”；要受托方整改的点“转 CAPA”，填措施、负责人和期限。**重大问题必须转 CAPA**。登记错的问题（还没转 CAPA）可以删除。照片、检查表在详情里上传。
3. **提交**：问题都处理了点“提交审核”。还有没处理的问题会提示是哪一条。
4. **审核**：质量安全负责人（不能是登记人或提交人）在列表上点“审核”，看过监督情况和问题，输入密码点“审核通过”；不充分的点“退回”并写原因，登记人补充后重新提交。
5. **到期提醒**：“受托厂”标签页列出每家受托厂最近一次监督；有在做的委托单、超过 90 天没有监督的标为“该去监督了”，总览也会提醒。
6. **CAPA 跟踪**：转出的 CAPA 在“质量体系 → CAPA”里登记完成和验证，监督记录上能看到 CAPA 的状态。

## 贮存环境（业务 → 贮存环境）

品牌方自己仓库各区域和留样室的温湿度，检查要点第 16 项（留样区域贮存条件）和第 20 项（贮存和运输）。

1. **设区域**（质量部门）：点“新增区域”，填编码和名称，选类型（仓储区、留样区、其他）和所在仓库，按产品标签和质量标准的贮存条件填温度、相对湿度的范围（不需要的留空，如只控温度上限就只填上限），选是否每天至少记录一次和从哪天开始算漏记，点“新增区域”。留样区的名称请和留样台账里的“留样地点”对应：地点以区域名称开头（如区域“品质部留样室”，地点“品质部留样室 B-01”）的留样算在这个区域里。范围以后可以改，改了不影响已有记录的判定。
2. **录入**（仓库）：在区域行上点“录入”，时间默认是现在，填温度和湿度，点“保存记录”。填的值超出范围时弹窗里会先提示。同一区域同一分钟只能记一条。
3. **导入记录仪数据**：在区域行上点“导入”，选记录仪导出的 CSV（Excel 文件请先另存为 CSV）。认得“时间”“温度”“湿度”和英文 Time、Temperature、Humidity 等表头，预检会列出有问题的行；库里这一分钟已有记录的自动跳过，可以重复导同一个文件。预检通过后点“确认导入”。
4. **超限**：超出范围的记录自动生成偏差（发生环节“仓储”），同一区域偏差还没关闭、相隔 24 小时以内的超限算一次、记在同一份偏差里。“超限”标签页列出每次超限的时间、读数、偏差和现在是否已恢复；点“详情”能看到这个区域现在的批次或留样，供评估影响。偏差在“质量体系 → 偏差”里调查和关闭，必要时冻结受影响的批次。
5. **作废**（质量部门）：录错的记录在“记录”标签页点“作废”，写明原因；记录保留、标为作废，同一时间可以重录。
6. **趋势图**：“记录”标签页选一个区域和日期范围，显示温度、湿度的趋势和范围线，红点是超限的记录；鼠标悬停或用方向键逐条看。导出按页面上的日期范围。

## 变更控制（合规 → 变更控制）

1. **提出**：除只读外的岗位都可以提出，写清原因、内容和范围。
2. **评估**：质量人员填风险等级和影响评估。勾选要变更备案、补做稳定性、更新标签、验证的，会自动生成行动项。
3. **批准**：另一位质量安全负责人输入密码批准。
4. **实施**：行动负责人做完后点“登记完成”。实施中发现还要做的事，质量人员可以加行动项。
5. **关闭**：行动全部完成后，质量安全负责人写效果确认并关闭。

发起配方变更时可以选关联的变更（实施中的配方或原料变更）。管理员打开开关后，**不关联已批准的变更就不能发起配方变更**。关联的配方签批或放弃之前，这项变更不能关闭。

提交标签设计稿时也可以选关联的变更（实施中的标签、包材或配方变更），设计稿详情和变更详情里都能看到。管理员打开开关后，**设计稿改版（第 2 版起）不关联已批准的变更就不能提交**，首版不受影响。关联的设计稿批准或退回之前，这项变更不能关闭。换供应商、改工艺等操作仍在各自页面做，系统不会自动关联。

## 标签设计稿（合规 → 标签设计稿）

1. **提交**：主数据或质量人员点“提交设计稿”，选成品和包材（包材要在这个成品的配方里），改版的可以选关联的变更，保存后上传设计稿文件。
2. **评审**：另一位质量安全负责人打开设计稿，对照页面上的全成分表草稿逐项勾选评审清单，输入密码批准。全部勾选、有设计稿文件才能批准。
3. **改版**：再提交一版，批准后旧版自动替代。成品配方变了，已批准的设计稿会提示要重新评审。
4. **打样和签样**：设计稿批准后，每家印刷供应商都要按这一版打样。采购或质量人员在设计稿详情里点“登记打样”，选供应商和收到样张的日期，保存后上传样张照片或扫描件。另一位质量人员打开打样，对照设计稿逐项核对、输入密码签样；不合格的写明原因，供应商改好后再登记一次。签样有问题的，质量安全负责人可以作废，这家要重新打样。
5. **包材放行**：有已批准设计稿的包材，在“检验放行”时要勾选“印刷内容与已批准的设计稿一致”。供应商送来的包材还要有这家供应商这一版的签样，弹窗里会显示签样编号，请对照签样核对颜色和印刷质量；没有签样的不能放行，可以拒收。设计稿要重新评审的，这批包材不能放行，可以拒收。
6. **印刷批次**：设计稿详情里列出按这一版放行的包材批次和现存数量。换版以后，旧版还有库存的会提示，请质量部决定用完还是报废；要停用就冻结批次。

## 新品立项（合规 → 新品立项）

1. **申请立项**：填产品名称、品类、备案类型、计划上市日期，管理员批准（不能批自己申请的）。
2. **开发**：在主数据建好成品后，在项目里“关联成品”。每次小试、中试都“记录试制”，中试要选配方版本。
3. **上市检查**：项目里逐项显示 8 项检查，没通过的点“去处理”跳到对应页面。“包材设计稿”要求配方里至少一个印刷包材的设计稿已批准。8 项都通过后点“提交上市”。
4. **批准上市**：另一位质量安全负责人输入密码批准，批准时会重新检查一遍。

批准上市只是记录，成品能不能卖仍要看每个批次的放行。

## 质量标准（生产与供应 → 质量标准）

**系统不内置标准值**，项目和限度按贵司标准填写。

1. **新建**：主数据或质量人员点“新建标准”，选物料，写原因，填检测项目。填了上下限的由系统判定，没填的由检验员判定。
   - **取样要求**（选填）：写了以后，检验员录入自检结果时要写取样情况（取了多少、从哪里取、谁取的）。系统不内置抽样方案。
   - **可采用供方报告**：勾了的项目可以不自检，照供应商或受托厂的检验报告录入；没勾的每批都要自检。
   - **连续采用供方报告最多几批**（选填）：填了以后，每家供方的首批要全项自检合格才能采用它的报告，连续采用到这个批数后，下一批要全项自检；不填就不限制。
2. **签批**：另一位质量安全负责人打开详情，输入密码点“签批生效”。旧版本自动替代。
3. **修订**：点生效标准的“修订”，会带入现行项目，改完提交，签批前现行版本照常使用。

**提供给受托厂**（质量标准 → 提供给受托厂）：在做的委托单里品牌供料的原料、包材，按受托厂列出现行标准、成分和受托厂的确认情况。受托厂在代工厂门户确认收到后显示“已确认”；标准修订签批后显示“确认的是旧版”，要受托厂重新确认。受托厂不用门户的，质量检验员或质量安全负责人在这一行点“登记线下交接”，填受托厂的接收人，点“登记交接”。有标准没确认的会进总览待办；“没有生效的标准”的物料要先建标准，原料“没有登记 INCI 名称”的到主数据补上。只提醒，不拦发料和放行。

**有生效标准的物料，放行前要先录检验结果**：

- 物料：在“检验放行”弹窗里点“录入检验结果”。
- 成品：质检员点“检验记录”录入，质量安全负责人再上市放行。

**采用供方报告**：标准里勾了“可采用供方报告”的项目，录入时勾“采用供方报告”，把报告上的数值或结果照填（仍按限度判定），再填供方检验报告编号，并在弹窗里上传报告扫描件（供应商、受托厂已经在门户里把报告传到采购单或委托单上的不用再传）。只有采购收货和委托生产的批次能采用；供方不在合格名录或资质过期、或者按标准这批轮到全项自检时，页面会写明原因，这批要全部自检。检验记录里采用供方报告的结果后面标“（供方报告）”。

在“质量标准”页点“导出检验结果”可以导出全部批次的检验结果，一个项目一行，含取样情况、结果来源和作废的记录，用来做趋势回顾和供应商评价。

最近一次检验合格才能放行，报告编号会自动填检验单号。不合格要写情况，系统自动生成重大偏差，偏差关闭并复检合格后才能放行，复检要写原因。**结果提交后不能改**，录错了请质量安全负责人作废后重录。没有标准的物料照旧按检验报告编号放行。

## 稳定性试验（合规 → 稳定性试验）

标的保质期要有依据。**系统不内置试验条件和合格标准**，按贵司方案填写，登记页预填的时间点和项目只是常用安排。

1. **登记**：主数据或质量人员点“登记试验”，选成品，填批号或样品来源、试验条件、开始日期、时间点和检测项目。一个样品放在一个条件下算一次试验，多个条件就登记多次。方案登记后可以在“修改方案”里加时间点、取消还没做的时间点、加检测项目（见下面第 6 条）。已经做了一部分的试验，把开始日期填成实际日期，按实际取样日期补录。
2. **录结果**：到时间了，质量人员点编号打开试验，点“录入结果”。计划日期前后 7 天内都可以；更早的不接受，更晚的要写原因。填了上下限的项目由系统判定。**结果提交后不能直接改**，请核对后再保存；录错了按下面第 7 条申请更正。样品不够、做不了的点“未取样”并写原因。
3. **不合格**：要写现场情况，系统自动生成一张重大偏差。批次还没放行的，偏差关闭前放不了行。**已放行的批次不会自动冻结**，请质量部判断要不要冻结或召回。
4. **写结论**：所有时间点都处理完后，填支持的保质期和结论。系统不判断结论对不对。
5. **签批**：另一位质量安全负责人签批；有未关闭的偏差不能签。

6. **修改方案**：试验进行中，质量人员点“修改方案”，可以加时间点、勾选取消还没做的时间点、加检测项目，写明原因、输入密码保存，每改一次记一版。已做的时间点和已有项目的限度不能改；要改限度就加一个新名称的项目（如“pH（新限度）”），结论里说明。
7. **结果更正**：在已检测的时间点点“申请更正”，选项目，填更正后的结果和原因。由另一位质量安全负责人在“结果更正”里批准后才生效，原结果保留。更正后不合格的会自动生成偏差；原来不合格改成合格的，偏差要在偏差处理里关闭。结论等待签批时不能更正，请先退回结论。

试验详情里会给有上下限的项目画趋势，超限的点标红。页面右上角“导出 Excel”导出全部试验的结果。

要纸质报告的，在试验详情里点“打印报告”，再点“打印”，纸张选 A4 横向。时间点超过 12 个会分成几张结果表。还没签批的报告顶部会标明“仅供内部参考”，取消或作废的标明“不能作为保质期依据”，不要拿去当保质期依据。

“保质期依据”页列出每个成品标的保质期和已签批的依据。配方变了，旧结论不再算依据。取样到期前 7 天开始提醒，超期算紧急。

## 询价比价

**采购**（询价比价 → 发起询价）：选物料、数量、邀请的供应商和截止日期。截止前能看到谁报了，看不到价格，这是为了防止串标。

**供应商**（门户 → 询价）：填含税单价、税率、交货天数和报价有效期。截止前可以改，其它供应商看不到。

**开标**：到了截止日期第二天自动可以比价；所有邀请的供应商都报完时，可以提前开标。

**下一轮议价**：开标或截止后，采购可填新截止日和议价说明。供应商可重新填写，或点“沿用此前报价”把上次提交的内容带入表单，再提交本轮报价。此前的有效期若早于本轮截止日，须重新选择。采购在列表可查看每家本轮已报的物料行数。

**定标**：由询价人以外的同事签批。系统从本轮有效报价中默认选每行最低价。不足 3 家报价、没选最低价或有报价却不定标，要写明原因。某一行没人报或都不合适，可以只定其它行。定标后自动生成带价格的采购单，每家供应商一张。

## 退货给供应商

**采购或仓库**（退供 → 发起退供）：选供应商和批次，填数量和原因。**质量**（退供 → 签批）：签批时才扣库存，签批人不能是发起人。

**发货**：签批后，采购或仓库可在总览的「退供待登记物流」点「去处理」，打开这张退供单，登记承运商和运单号。供应商在门户的「退货」可看到发货信息，收到后点「确认收到退货」，可填写签收备注。填有邮箱的供应商账号会在每日摘要里看到本单位待签收的退货。确认时间和备注可在退供单或导出的 Excel 中查看。

**代录签收**：供应商没有启用的门户账号时，采购在收到线下回单后，从总览的「退供待代录签收」打开退供单。点击「代录签收」，填写实际签收日期和回单或凭证编号，输入签批密码后登记。退供单、批次追溯和 Excel 会区分门户签收与采购代录。待办在登记后结束。

结算前退的，结算数量自动减掉；已经结算的，下一张对账单自动生成负数行冲减。冲减超过当期货款时，可以选择生成红字冲减对账单。质量签批后的退供记录可在批次追溯和供应商门户查看。

## 对账结算

采购、财务、管理员能看全部页签。销售进来只看到客户应收（见下面“客户应收和信用额度”），供应商对账单、进项发票和应付账龄不显示。

只结算**检验放行**的来料批次。待检、不合格、冻结的不结算，等有结论再说。

1. **采购生成对账单**（对账结算 → 生成对账单）：选供应商和截止日期，确认明细。账期留空使用供应商默认账期，未设置时为 30 天；可以手填 0 天。到期日为截止日期加账期。采购单没单价的批次不会进去，先到采购入库点“单价”录入。质量扣款填在调整金额里，写明原因。
2. **供应商确认**（门户 → 对账）：金额不对就“提出异议”，采购核对后作废重新生成。
3. **登记发票**：供应商确认后按票填写号码、日期、实际税率和含税金额，可录入多张蓝字、红字发票。红字填负数，发票合计须与对账单一致。没开门户的供应商由采购代登记。票号已用于该供应商的其它有效单据时，系统会提示对应对账单号。
4. **财务审批**：审批人不能是制单人，要签批。发票信息有误时，财务可填原因并签批退回。供应商在原对账单点「更正发票」，也可由采购代更正。系统带入上次发票，重新提交后由财务审核最新一版。原对账明细、已确认的金额和每次退回记录均可查阅。
5. **收付跟进**：在结算列表查待付款、待收退款或已逾期的单据。总览按付款与退款显示到期情况，今日到期和已逾期的事项进入财务的每日提醒。付款与收到的退款都可分次登记，结清后退出待办。实际资金收付通过银行或财务系统完成。

对账预览、详情、审批和收付登记会列出所含批次对应的待处理收货异议。采购可点送货通知单号查看说明并答复，财务可在“对账跟进”选择“收货异议待处理”，集中查看涉及异议的在办对账单。

生成对账单后批次被冻结或判不合格的，不能审批和付款，要等质量结论，或作废后在调整金额里扣掉再重新生成。

**价格和金额只有采购、财务、管理员能看。** 其它岗位在审计日志里看到的是“含金额，采购和财务可见”，操作记录还在，只是内容被遮盖。

这些规则都是默认值，见 `docs/SRM-默认规则.md`。

**委外加工费对账**：生成对账单时选“【委外】受托厂名称”，带入已上市放行的委托单，金额按实际产量 × 单位加工费算。关联的委托单有品牌供料超耗时，预览里会逐项列出，可以点“按超耗建议填入扣款”，把按标准成本折算的金额和原因填进调整金额，扣不扣、扣多少可以再改。受托厂在门户确认和登记发票；没开门户的，采购点“确认对账”“代登记发票”。之后的审批、付款和采购对账一样。

## 客户应收和信用额度（对账结算 → 客户应收对账）

销售、财务、管理员能看。销售在左侧菜单点“对账结算”，进去就是“客户应收对账”，还有“应收催收看板”和“账龄分析”（只有应收账龄）。客户的默认信用账期、税率和信用额度在“主数据 → 往来单位”里填，信用额度留空表示不限。

1. **生成应收单**（销售或财务，点“生成客户应收单”）：选客户和对账截止日期。截止日及以前出库、还没进过应收单的出库行都会带进来；同期登记的销售退货自动生成负数行冲减。出库时没有单价（没填，也没有协议价）的行不会进应收单，选好客户和日期后弹窗里会提示有几行，先到“销售出库 → 缺单价”补上（见“销售”第 8 条）；常卖的成品先维护客户协议价。按 0 元定价的赠品行也不进应收单。信用账期留空按客户默认，客户也没填的按 30 天，到期日是截止日期加账期。填了调整金额要写原因。
2. **登记销项票**（财务）：填销项发票号。
3. **审批**（财务）：输签批密码。审批人不能是生成这张应收单的人。
4. **登记回款**（财务）：填本次回款金额，可以分几次登记，收齐后显示“已结清”。
5. **作废**（财务）：还没审批的可以作废，要写原因。里面的出库行和退货行会释放出来，下次重新对账。
6. 详情里点“打印对账函”，寄给客户盖章确认。经销商在门户的“应收对账”里也能看到自己的对账单。接了财务系统的，财务点“导出应收凭证”，或者由财务系统通过接口拉取凭证、回传回款，同一笔回款重复回传只记一次。

**催收和账龄**：“应收催收看板”列出已审批、还没收齐的应收单，分成严重或超额逾期、已逾期、7 天内到期、授信超额几类，每行有催收建议，财务可以直接点“登记回款”。“账龄分析”切到“应收账龄（客户）”，按客户看未到期和逾期各段的金额。

**信用额度怎么算**：销售出库、审核经销商订单、电商订单出库时，系统把“未结清的应收单待收 + 已出库还没进应收单的金额 + 本次出库金额”和信用额度比较，超过就不能出库，提示里会写出其中已出库未对账多少。

- 只算有单价的出库行。没有单价的行补上单价后马上计入；“客户授信概览”的“已出库未对账”下面会写另有几行没单价。
- 登记回款后额度马上释放。
- 退货在进了应收单、冲减以后才释放额度；登记了退货还没对账的，不先扣。要早点释放，就先生成应收单。
- 点右上角“客户授信概览”，可以看到每个客户的授信额度、未结应收、已出库未对账和可用额度，算法和出库时一样。

单价、协议价和应收金额只有销售、财务、管理员能看。

## 采购和仓库：怎么用供应商的信息

- **下单**：期望到货日选填。没有期望日、供应商也没回复的单子不计入准时率。录入单价后，税率留空使用页面显示的供应商默认税率，可以手填其它税率。
- **采购页的“交期”列**：有回复显示供应商回复，没有显示采购期望；超期标红。“供应商未确认”只在对方开了门户账号时才显示。
- **收货时选中送货通知**，会带入该通知里的物料、批号、日期和数量。请按实物填写本次收货数量和批号，未到的物料填零，通知之外的物料另行手工收货。实收批号和通知一致时自动带入该批的 COA 编号和附件；如有差异，请按实物收货并补传实收批次的 COA。采购单收齐后，尚未核对的通知显示“随订单关闭”。
- 从总览的**收货异议待处理**进入，核对送货通知、实际收货和供应商说明，填写处理结果后发送答复。采购页可按采购单回看异议和答复。
- **供应商评分**（质量体系 → 供应商审核）：质量 50、交货 30、审核 20，没有数据的项不计。只作参考，不影响下单，能不能下单还是看合格名录和资质。供应商看不到这个分。
- **开账号**：账号管理 → 新增账号 → 外部门户角色选“供应商门户”，选所属单位。填了邮箱的账号每天早上收到提醒：待确认的采购单、3 天内的交期、到期的资质，没有事项不发。提醒只在定时任务发出，“立即发送一次”不发给供应商。

## 经销商门户

“可订数量”已按贵方的效期标准算好。填订购数量后提交，品牌方审核通过就发货，批号显示在“我的订单”。收到召回通知要在“召回”里确认。
“应收对账”里能看到品牌方给贵方的对账单、应收合计和到期日，有疑问联系品牌方销售。

## 各类看板

看板都是只读的，帮各岗位找出快到期、超期或卡住的事。看板上的按钮调用原来的业务操作，权限、签批和原来一样。看板大多可以导出 Excel，金额按岗位权限显示。

| 在哪里 | 看板 | 看什么 |
| --- | --- | --- |
| 采购入库 | 在途催货看板 | 已超期、7 天内到期、已发货待收的采购单 |

| 质量体系 | 闭环升级监控、供应商审核 | 偏差和 CAPA 超期、阻断放行、待 QA 验证；往来单位资质快到期或已过期 |

| 销售退货 | 退货处置复盘 | 退货原因和处置结果 |
| 电商对接 | 异常重试监控、健康度与失败复盘 | 失败的电商订单和接口调用 |
| 对账结算 | 应收催收看板、账龄分析 | 见上面“客户应收和信用额度” |
| 库存 | 效期处置建议（列表里的一列） | 临期、过期批次怎么处理，点“导出效期风险”导出 |
| 经营看板 | 供应商绩效、批次实际成本、毛利、现金流和库存损益、库存 ABC、呆滞库存 | 经营分析，金额是标准成本估值，不是账面成本 |
| 配方与备案 | PQR、PIF、原料反查 | 年度质量回顾和产品信息档案可以打印 |

## 常见提示

| 看到的提示 | 什么意思，怎么办 |
| --- | --- |
| 账号或密码不正确 | 检查输入。连续 5 次会锁定 |
| 登录失败次数太多，请 1 分钟后再试 | 同一网络出口失败太多，等 1 分钟 |
| 数量最多 14 位整数、4 位小数 | 小数位太多，系统不会悄悄四舍五入，请改数量 |
| 用到的物料批次……有问题，不能放行 | 物料被冻结或不合格。先调查，解冻后再放行，或判定不合格 |
| 批次……有进行中的召回，要先关闭召回才能解冻 | 召回没结束不能解冻 |
| 没有收到服务器响应，操作可能已经完成 | 网络断了或服务器太慢，单据可能已经建好。先刷新页面看一眼，确实没有再重做，否则可能多一张单 |
| 批次……在该仓没有库存记录，不能盘点 | 盘点表不是这个仓的。关掉弹窗重新打开，再按新的盘点表填 |
| 页面加载失败，请检查网络后刷新重试 | 网络不通，或系统刚升级。恢复网络后刷新页面 |
| 数据刚被其他人修改，请刷新后重试 | 两个人同时操作了同一张单，刷新看最新状态 |
| “……”被 Excel 显示成了科学计数 | 长数字的后几位已经丢了。把这一列设成文本格式，重新填写后再保存 |
| “……”是 Excel 的错误值或列太窄显示的 | 公式出错，或列太窄显示成 ####。在 Excel 里改好或拉宽列再保存 |
| 这些列系统不认识，不会导入 | 列名和模板不一样。要导入的列改成模板里的名字；备注之类的不用管 |
| 第 …… 版还没有上传文件，不能签批 | 在文件详情里选这一版，上传文件后再签批 |
| 还有行动没完成 | 行动负责人登记完成后再关闭变更 |
| 评审项没有全部确认 | 对照设计稿逐项勾选评审清单 |
| 提交后成品的生效配方变了 | 退回这一版，按新配方重新提交 |
| …… 还没有设计稿 …… 的签样 | 到“标签设计稿”里给这家供应商登记打样并签样，再放行；样张不合格就拒收 |
| 核对项没有全部确认 | 对照设计稿逐项核对样张后勾选 |
| 上市检查没通过：…… | 按提示到对应页面补齐，项目里点“去处理” |
| …… 已关联项目 …… | 这个成品已经属于别的项目，先确认是不是选错了 |
| …… 有生效的质量标准，请先录入检验结果 | 在放行弹窗或“检验记录”里录入结果 |
| 最近一次检验 …… 不合格，不能放行 | 处理偏差，复检合格后再放行；或判定不合格 |
| …… 已有一个待签批的标准 | 先让质量安全负责人签批或退回，再提交新版本 |
| 标准有取样要求（……），请填写取样情况 | 在录入弹窗里写取样情况；全部项目都采用供方报告时不用写 |
| 请先上传供方检验报告 | 在录入弹窗下方上传报告扫描件，再保存 |
| …… 还没有全项自检的记录 / 已连续 … 批采用供方报告 / 最近一次全项自检 … 不合格，这批要全项自检 | 这批所有项目都自检；合格后下一批可以再采用供方报告 |
| …… 不在合格名录或资质已过期，不能采用其检验报告 | 这批自检；供方重新审核合格或更新资质后才能采用 |
| 最早 …… 才能取样，时间不够的结果不能作为依据 | 还没到取样时间。放的时间不够，结果不能作依据 |
| 偏差 …… 还没关闭，不能签批结论 | 到“质量体系”关闭偏差后再签 |
| 结果提交后不能直接改；录错了请申请结果更正 | 在试验详情里对这个时间点点“申请更正”，由另一位质量安全负责人批准 |
| 有结果更正待审批，审批后再写结论 | 请质量安全负责人先批准或驳回更正 |
| …… 要改限度请加一个新名称的项目 | 已有项目的限度不能改，加一个新项目，结论里说明 |
| 配方合规校验未通过：……为禁用原料 | 物料上标了禁用，或法规目录里是禁用。看“合规资料 → 法规目录” |
| 还没有生效配方 | 先录入配方，再登记合规资料 |
| …… 的生产许可项目没有标注具备眼部护肤类（儿童护肤类）化妆品生产条件 | 成品标了这一类，工厂许可证上没有相应标注。许可证上确实有的，到“主数据 → 往来单位”给工厂勾上；成品类别标错的，改成品主数据；都不是的，换有相应条件的受托厂 |
| 签批人不能是登记人 | 请另一位质量安全负责人签批 |
| 定标人不能是询价人 | 请另一位有权限的同事签批 |
| 审批人不能是制单人 | 请另一位财务签批 |
| 发票金额……和对账单合计……不一致 | 核对发票。确实不一致的，作废对账单重新生成，把差额写进调整金额 |
| 不是采购来的，不能退给供应商 | 期初导入和生产的批次不能退供，用报废 |
| 还能退……（在库……，待签批……） | 已有退供单占用了额度。发错的先取消 |
| 合计要大于 0 | 退货冲减超过了货款，等有新货款再一起结算 |
| 批次……已不是放行状态 | 批次被冻结或判不合格了。等质量结论，或作废对账单重新生成 |
| 已进了对账单，不能改单价 | 要改先作废对账单 |
| 修改交期要写明原因 | 供应商改交期必须写原因，留有记录 |
| 超过还能通知的数量 | 未收的数量已被别的送货通知占用。发错的通知先取消 |
| 请先确认订单并回复交期，再发送货通知 | 先点“确认订单” |
| 表头缺少…… | 导入文件的表头不对，点“下载模板”用模板填 |
| 这是 Excel 工作簿（.xlsx）…… | 在 Excel 里“另存为 CSV”后再上传 |
| 客户……信用额度不足：……（其中已出库未对账 ¥……） | 未结应收加上本次出库超过了授信额度。先生成应收单、登记回款，或在主数据调整信用额度。退货要进了应收单才会释放额度。提示里写“另有 N 行出库还没有单价”的，那些行补上单价后还会再占额度 |
| 这些出库行已进应收对账单，不能再改单价 | 请财务先作废这张应收单，改好单价后重新生成 |
| 改已有单价或按 0 元定价（赠品、样品）要写明原因 | 在原因里写清楚，比如“按年度合同价更正”“渠道试用装，不收款” |
| 没有可结算的销售出库行：截止日前有 N 行出库没有单价 | 到“销售出库 → 缺单价”补上单价再生成 |
| 有调整金额时要写明原因 | 在“调整原因”里写清楚为什么调整 |
| 退库数量不能超过该批次的净发料量 …… | 这个批次实际发给这张单的量比填的少，按实际余料填 |
| 生产单……已进了对账单，不能改加工费 | 先作废委外对账单，改好加工费再重新生成 |
