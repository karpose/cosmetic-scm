# SRM 默认规则（V28 已升级）

## 询价比价
- **比价最少家数**：3 家。不足 3 家能定标，但要写原因（`RfqService.MIN_QUOTES`）
- **没选最低价**：能定标，但要写原因（`RfqService.award`）
- **比价依据与历史采购价参考**：按含税单价排序对比，同时自动关联展示该物料最近一次有效采购单单价（`lastPoPrice`）及涨跌幅百分比（`RfqService.views`）
- **多轮议价**：开标或截止后，采购可设新截止日期和议价说明，开启下一轮封标。供应商可在门户填新价，或选“沿用此前报价”带入上次提交的内容，再确认本轮报价。此前报价的有效期保留；不足新截止日期时，供应商须填写新的有效期。本轮比较和定标只使用本轮实际提交的报价。
- **询价物料范围（V28 扩展）**：支持原料（`RM`）、包材（`PKG`）及半成品委外加工（`WIP`）询价（`RfqService.create`）
- **封标**：开标或截止前，内部只能看到各供应商的本轮报价行数。审计日志不记封标报价金额，未开标的询价取消后也不会公开报价。
- **提前开标**：所有受邀供应商在本轮报完所有物料才可以。供应商只报部分物料时，采购可等到截止后比价。
- **定标人**：不能是询价人，要输入签批密码（`RfqService.award`）

## 对账结算
- **哪些批次能结算**：只有**已放行**的。待检、不合格、冻结的都不结算（`SettlementService.unbilled`）
- **收货异议提醒**按对账明细涉及的批次显示采购单和送货通知。采购回复后提醒移除。结算数量、金额和审批条件仍按原有结算规则计算。
- **往来单位财务档案与默认账期/税率（V37 新增）**：在主数据“往来单位”可维护税号、开户银行、银行账号、默认信用账期（天）、默认税率（%）与财务客商编码。新建采购单录入单价时，税率留空采用当前供应商的默认税率（页面未设时显示 13%）；生成对账单时，账期留空采用当前供应商的默认账期（未设为 30 天）。切换供应商会更新页面提示的默认值，保留手填的税率和账期，手填 0 也有效。
- **账期与到期提醒**：生成对账单时可设置账期（默认 30 天，范围 0～365 天，未填时优先取往来单位默认账期）。到期日为对账截止日加账期。已审批且未结清的单据按付款或退款进入收付跟进，按到期日排序。今日到期或逾期的事项进入财务每日提醒，提醒正文列出供应商、单号和到期情况。结清后退出待办。
- **多税率自动拆分汇总（V28 新增）**：对账单预览与详情自动按税率升序拆分汇总各档税率的含税金额、不含税金额和税额（`SettlementRule.breakdownByTaxRate`）
- **一单多票与蓝/红字发票**：供应商和代登记的采购可按发票填写税率，区分蓝字（正数）与红字（负数）。对账单只有一个税率时将它带入表单，可以按实际发票修改。发票含税总额须等于对账单合计。
- **票号查重**：同一供应商的有效对账单不能重复使用同一发票号。比较时忽略首尾空格和字母大小写，冲突提示会给出已登记的对账单号。退回和作废后，原记录留档，票号可重新登记。
- **红字冲减对账单与供应商退款（V28 新增）**：当结算后退货冲减超过当期新入库货款（`totalAmount < 0`）时，支持勾选“允许生成红字冲减对账单”，由供应商登记红字发票，财务审批后通过 `POST /api/statements/{id}/refund` 登记供应商退款（`SettlementService.refund`）
- **审批人**：不能是制单人，要输入签批密码（`SettlementService.approve`）
- **外部财务系统对接（V39 新增）**：
  - 凭证拉取/导出：外部财务系统可通过 `GET /api/integration/finance/vouchers`（`X-Api-Key` 认证，支持 `syncStatus`、`pendingOnly` 过滤）拉取已审批/已结清对账单（含往来单位税号、开户行、财务客商编码、分税率汇总、发票与批次明细）；内部财务也可在结算页通过 `GET /api/statements/finance-vouchers` 导出凭证 JSON。
  - 凭证回执：`POST /api/integration/finance/vouchers/{statementNo}/ack` 回写外部凭证号与同步状态（`SYNCED` / `FAILED`）。
  - 付款水单回调核销：`POST /api/integration/finance/payments` 按外部付款单号（`extPaymentNo`）幂等核销付款或红字退款，重复推送直接返回幂等结果而不重复扣减未付金额。
- **发票退回与更正**：财务可在审批前签批退回并填写供应商可见的原因。原对账单和批次保留，退回的发票及原因留档。供应商或采购在原单重提后，财务须审核最新提交。采购和供应商的每日提醒包含待更正事项。
- **谁能看价格**：采购、财务、管理员。其它岗位接口不返回单价，审计记录遮盖成“含金额”

## 交付协同
- **收货回执**按采购单列出本单位的采购收货批次、实收数量、供应商批号和当前质检状态。
- **送货通知逐批绑定 COA（V38 新增）**：供应商发送货通知（ASN）时可按明细行填写对应批次的 COA 报告编号并上传 COA 附件；仓库按该送货通知收货且实收批号与通知一致时，系统将 COA 编号和附件挂载到对应批次上，质量检验时自动预填。批号不一致时按实物收货，保留送货通知和收货差异，提示补传实收批次的 COA。
- 仓库**按送货通知收货**时，系统保存实收批次与通知的对应关系，并向供应商显示数量或批号差异。手工和历史收货按采购单显示回执。订单收齐时，尚未核对的通知随订单关闭。
- 有数量或批号差异的通知可提交一次**收货异议**。采购或管理员核对后填写供应商可见的答复。异议进入采购待办，答复后移出。异议和答复随通知留存，库存和对账仍以实收及原有业务流程为准。

## 供应商评分和提醒
- **评分权重**：质量 50、交货 30、审核 20，没有数据的项不计（`SupplierScore`）
- **等级线**：A ≥ 90, B ≥ 75, C ≥ 60, 其余 D（`SupplierScore`）
- **准时率**：按第一次承诺的交期算，没承诺过看采购期望（`PurchaseOrderRepository.deliveryStats`）

## 退货给供应商
- **能退什么**：采购来的批次，任何状态（待检、放行、不合格、冻结）。期初导入和生产的批次不能退（`SupplierReturnService.create`）
- **谁发起与签批**：管理员、采购、仓库发起；QA 或 QSO 签批（不能是发起人，要输入密码），**签批时才扣库存**（`SupplierReturnService.approve`）
- **退货物流与供应商门户签收确认**：
  - 质量签批后，总览列出待登记物流的退供单，采购和仓库可从待办直接打开单据，登记承运商和运单号。
  - 物流登记后，供应商可在门户确认收到本单位的退货，签收备注选填。已发出待签收的退货排在门户列表前面，并在每日供应商提醒中列出，确认后退出提醒。
  - 供应商没有启用的门户账号时，采购或管理员可凭线下回单签批代录。实际签收日期须在质量签批当天至今天之间，回单或凭证编号必填。系统另外保留代录人和登记时间；每张退供单只登记一次签收。
- **对账联动**：结算前退的自动扣减结算数量；结算后退的在下一张对账单生成负数冲减行（`SettlementService.unbilled`）
